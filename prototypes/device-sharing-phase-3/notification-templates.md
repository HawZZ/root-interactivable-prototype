# 设备共享三期：通知与注册模板

Source: [设备共享三期 PRD](https://momcozy-in.feishu.cn/docx/X11Hd0jKmon6qlxkbfvcD7MznNc)；2026-10-12 已确认的通知模板定义。

邮件、短信、H5 均按厂商区分内容；下面给出完整变量、布局、格式及文案。补发与注册过程的业务判定见 [设备共享三期 PRD](https://momcozy-in.feishu.cn/docx/X11Hd0jKmon6qlxkbfvcD7MznNc) 第 5.2–5.3 节。中文为内容基准，英文须逐项保持语义；邮件发件地址、帮助中心、H5、商店 URL 及二维码由对应生产系统配置。

## 1. 模板变量与布局约束

| 变量 | 来源与展示规则 |
| --- | --- |
| `{nickname}`、`{device_name}` | 分享者注册资料中的必填 Nickname、当前设备名称；通知和 H5 使用同一快照，不写死原型示例 Alex/Baby Monitor 05 |
| `{invited_account}` | 本次输入并规范化的受邀邮箱或手机号；邮件正文可显示完整邮箱，H5 首屏脱敏展示，注册表单预填完整账号；短信不重复展示完整号码 |
| `{owner_region}` | 分享者发起时的账号国家/地区；邮件、短信和 H5 均展示，作为注册地区建议，不作为国家代码必须相等的断言 |
| `{h5_url}` | 一次通知只放一个指向对应厂商 H5 的签名链接；自研和 Tuya 不设置时间到期、不展示 `expires_at`；Tuya 分享码成功使用上限固定为 1，已用尽或已撤销的邀请不能再次建联；Meari 不创建未注册共享邀请 |

- **邮件布局**：邮件客户端列表展示发件人 `Momcozy`、第 2 节 的主题和预览摘要。详情页使用白底、居中单列，从上到下固定为：Momcozy 品牌标识；问候与邀请说明；独立的时效/注册指引提示段；受邀账号说明；地区与数据中心提示；一个全宽主按钮 `打开注册网页`；自动发送与帮助中心页脚。正文移动端左右留白不小于 16px，段落左对齐、按钮文本居中；标题/提示/按钮与普通段落有清楚的视觉层级。二维码、应用商店按钮和注册表单只放 H5，不在邮件内复制。发件地址及帮助中心生产 URL 沿用通知系统配置，原型地址不作为生产承诺。
- **短信布局**：复用系统短信会话，不设计 APP 内预览页；一条消息按“【Momcozy】标识 → 分享者与设备 → 厂商特定时效/后续动作 → `{owner_region}` 建议 → 唯一 H5 链接”的顺序连贯排布，不插入图片、二维码或第二个链接。点击会话先看完整短信，点击正文链接才进入 H5；短信拆分计费不改变一次业务通知与幂等计数口径。
- **H5 布局**：移动优先、居中单列，内容区左右留白 16px；初始页面从上到下为“Momcozy 标识 → 厂商标题和设备说明 → 邀请时效/注册指引提示区 → 脱敏受邀账号和 `{owner_region}` 提示 → 全宽 `立即注册` 主按钮 → 下载区标题 `下载 Momcozy App` → APP 二维码及说明 `扫码下载 Momcozy App` → App Store 与 Android 应用商店并列按钮 → `在 APP 中完成注册/登录` 指引区”。二维码、两个商店按钮均是下载入口，注册是主操作，不因下载入口并列而降级；APP 指引区服务不愿意在 H5 直接注册的用户，与 `立即注册` 是并行路径，不替代主操作。小屏允许纵向滚动，不用弹窗遮挡注册、下载或 APP 注册/登录指引；桌面端保持居中窄列。注册成功页保留下载/打开 APP 入口。H5 链接与商店地址由技术配置，模板中不出现原始 Tuya 分享码。
- **共同地区文案**：`建议选择共享者的国家或地区「{owner_region}」注册并登录；如果选择其他国家/地区，可能无法查看共享设备及设备数据。` 不写成国家代码不同就必然不可见。模板语言沿用分享者 APP 语言；下述中文文案为内容基准，英文版须逐项对应，不得改变厂商结果或有效期。

## 2. 邮件模板

Tuya 共享码的成功建联上限属于后台执行规则，邮件、短信、H5 和 APP 面向用户的提示不展示“仅接收一次”“一次性使用”等说明；该文案调整不改变每码最多成功建联 1 次的限制。

### 邮件模板 · 自研

```yaml
模板: 三期未注册邀请邮件 · 自研
适用对象: 未注册邮箱
发件人: Momcozy
主题: '{nickname} 邀请你接收「{device_name}」的共享'
收件箱摘要: 请使用受邀账号注册并登录 Momcozy App，接收设备分享。
---
布局顺序:
  - Momcozy 品牌标识
  - 正文
  - 全宽主按钮
  - 页脚
正文:
  - '你好，{nickname} 邀请你接收设备「{device_name}」的共享。'
  - '请使用收到本邮件的邮箱「{invited_account}」完成注册并登录 Momcozy App，接收设备分享。'
  - '建议选择共享者的国家或地区「{owner_region}」注册并登录；如果选择其他国家/地区，可能无法查看共享设备及设备数据。'
主按钮:
  文案: 打开注册网页
  链接: '{h5_url}'
页脚:
  - 此邮件由 Momcozy 系统自动发送，请勿直接回复。
  - 如需帮助，请访问 Momcozy 帮助中心。
展示与操作约束:
  - 邮件客户端展示发件人、主题和收件箱摘要；正文单列白底，段落左对齐，按钮居中。
  - 只放一个 H5 链接；二维码、应用商店按钮和注册表单不出现在邮件内。
  - 补发正文和原邀请保持不变；不创建新邀请、不重复占额，仍受通知冷却及次数限制。
```


## 4. H5 模板

### H5 模板 · 自研

```yaml
模板: 三期未注册邀请 H5 · 自研
title: 注册后接收设备分享
subtitle: '{nickname} 邀请你使用「{device_name}」。'
---
首屏布局:
  - Momcozy 品牌标识
  - 标题
  - 副标题
  - 高亮提示区
  - 受邀账号与地区建议
  - 主按钮「立即注册」
  - 下载区「下载 Momcozy App」
  - APP 注册/登录指引区
提示区文案: 请使用受邀账号完成注册并登录，接收设备分享。
受邀账号: '{invited_account}'
地区建议: '建议选择共享者的国家或地区「{owner_region}」注册并登录；如果选择其他国家/地区，可能无法查看共享设备及设备数据。'
主按钮:
  文案: 立即注册
  动作: 进入 Plan A 同页注册或 Plan B 同标签页注册跳转
下载区:
  标题: 下载 Momcozy App
  QR: APP 下载 QR 码
  应用商店:
    - App Store 下载链接
    - Google Play / Android 应用商店下载链接
APP注册登录指引:
  标题: 在 APP 中完成注册/登录
  说明: 如果不想在 H5 直接注册，可先下载或打开 Momcozy App。
  步骤:
    - 下载或打开 Momcozy App。
    - 使用受邀账号「{invited_account}」注册或登录。
    - 按建议选择「{owner_region}」；如果选择其他国家/地区，可能无法查看共享设备及设备数据。
    - 原邀请未撤销时，使用受邀账号登录后设备列表出现「{device_name}」。
  视觉:
    - APP 注册页面示意，高亮账号输入和地区选择
    - APP 设备列表页示意，展示「{device_name}」
注册模块:
  承载方式: Plan A 同页完整注册 / Plan B 同标签页跳转既有注册页并回跳
  字段顺序:
    - 预填受邀账号
    - 邮箱验证码及发送/倒计时
    - 密码及显隐
    - First Name（0/50）
    - Child’s Birthday/Due Date
    - 国家/地区
    - 必选隐私政策与服务协议
    - 可选 Newsletter
    - 创建账号
完成页:
  有效且账号/数据中心条件满足: '注册完成。使用当前账号登录 Momcozy App 后，系统将自动添加共享设备。'
  邀请已失效: '账号已创建，但无法通过本次邀请完成设备共享。请联系 {nickname} 重新分享设备。'
  布局:
    - 结果标题
    - 结果说明
    - 打开 Momcozy App 主按钮
    - 下载 Momcozy App 二维码
    - App Store / Android 应用商店按钮
展示与操作约束:
  - 注册是主操作；下载区和 APP 注册/登录指引是并行路径，不降低注册入口优先级。
  - 中国国内 Android 模板固定中国且不展示地区选择器。
  - 注册过程中邀请撤销或失效时提示“本次分享邀请已失效。你仍可完成账号注册，请联系 {nickname} 重新分享设备。”
  - 账号不匹配无法建联；数据中心不兼容可能无法查看设备及数据；均不撤销仍有效的原邀请。
```
