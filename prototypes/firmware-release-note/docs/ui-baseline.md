## 本次新增设计

原型复用上述骨架、列表列顺序、控件密度和两种信息抽屉宽度。按用户2026-11-06最新决定，在两类列表的操作列新增Release note入口，打开760px独立管理抽屉。六种生命周期状态均保留该入口和说明操作：对象上下文、固件包、冻结状态及发布配置只读；语言、Markdown源码、导入和单独保存按平台权限可用；Markdown预览为只读渲染。对象状态在编辑、导入预检或保存期间变化时，不关闭抽屉、不清空表单或草稿、不使合法预检失效。

原新建、编辑及详情信息抽屉保留既有用途，不嵌入Release note编辑器；发布日志、备注、包信息、应用对象及组件保持现状。对象创建成功自动生成英语默认值，随后从列表独立维护。独立管理抽屉是本次新增设计，非现状事实；样式沿用平台，不替换既有信息。列表和既有字段使用样例，不连接测试或生产数据。

右侧批注和编号是评审工具，不属于产品UI；其中的场景切换、模拟失败、存量初始化与APP读取验证均为原型工具。APP验证只展示读取已保存内容、对象/语言及渲染结果，不推定真实APP升级页面布局。现状对照开关隐藏新增内容，用于辨别改动范围。

## 证据强度与实施边界

现场列表只观察到开发中对象；其他状态使用样例呈现并用于核对全生命周期入口，不能称作现场状态验证。本地wiki提供全局视觉参考，旧可控发布原型只参考业务规则，不把其148px侧栏当现状。全生命周期可编辑与列表入口是当前需求，其他状态的线上可用性仍须实施验收；新增字段位置、预检呈现和列表入口为本次设计，非已上线事实。原型不重建与本需求无关的发布/包上传业务，既有入口只保留外观并提示范围。

原型使用演示上限（单语言10000 UTF-16代码单元、文件1MiB）及保守Markdown策略，不作为生产冻结数值；实际共同元素、URL策略、长度和资源上限由技术实施前冻结并按review-contract.md验收。不存在旧Release note译文迁移。
