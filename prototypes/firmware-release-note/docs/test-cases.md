# 固件支持 Release note 及多语言配置｜测试用例附录

更新日期：2026-11-06。关联：[PRD](PRD.md)、[多语言导入说明](import-spec.md)、[补充验收规格](review-contract.md)。

本附录完整承接 28 条测试用例，保持五列结构及当前验收意图。补充矩阵 MD01–MD10 和异常导入边界按[补充验收规格](review-contract.md)执行；以下均为待实施验证，不表示真实平台、APP 或数据初始化测试已经通过。

| 用例名称 | 前置条件 | 输入 | 操作 | 预期结果 |
| --- | --- | --- | --- | --- |
| 创建默认英文（AC01） | 分别创建MCU、模组、虚拟版本 | 合法对象信息 | 在既有信息表单完成创建，再从列表操作列打开Release note | 三类对象英文均为 `Bug fixed`，其余15语言使用英语兜底 |
| 自定义Markdown（AC01、AC11） | 已创建对象 | 含标题、列表、强调、链接及换行的Markdown | 从列表Release note进入独立管理，编辑、预览、保存再打开 | 源码保留，平台预览与内容相符 |
| 六态可编辑（AC02） | 分别有开发中、测试中、发布中、暂停发布、已停止、已发布对象 | 修改说明 | 逐一从列表进入并编辑、预览、保存 | 六态均可保存，仅说明变化；状态、包、冻结、组件、备注及发布配置不变 |
| 首次已发布继续编辑（AC02） | 对象首次发布已完成 | 修正后的说明 | 打开独立管理界面编辑并保存 | 保存成功，状态仍为已发布，不因首次发布锁定说明 |
| 定时状态切换（AC03） | 测试中对象已设置定时全面发布 | 新说明 | 状态生效前编辑并保留输入，状态切换为已发布后提交保存 | 输入未清空，状态变化不阻断，保存成功 |
| 预检跨状态变化（AC03） | 对象处于发布中，导入文件已预检通过 | 含新语言内容的Excel或CSV | 状态切换为已发布后应用并主保存 | 合法预检仍有效，草稿未清空，应用及保存成功 |
| 16语言与非必填（AC04） | 英文为默认值 | 16种语言 | 逐一切换，不填写其他15种语言并保存 | 共16种，默认英语；其他语言可为空且显示英文 |
| 配置语言优先（AC04） | 英语有效、德语有内容、法语为空 | 德语、法语 | 分别读取 | 德语返回自身内容，法语使用英文 |
| 修改英文后兜底（AC04） | 已配置德语，法语为空 | 修改英文 | 保存后读取 | 法语读取新英文，德语独立内容保持原值 |
| 英语非空（AC04） | 可编辑对象 | 空英文或纯空白 | 保存 | 提示英语必填，不写入变更 |
| 移除非英语（AC04） | 法语已独立配置 | 清空法语 | 保存后读取 | 法语恢复英文兜底 |
| Excel导入（AC05、AC11） | 当前对象存在 | 16语言Excel文件，含多行Markdown | 预检、应用、主保存 | 各语言及Markdown换行正确保存 |
| CSV导入（AC05、AC11） | 当前对象存在 | 含逗号、引号和换行的UTF-8 CSV | 导入并保存 | 正确解析单元格，源码与换行完整 |
| 部分语言与空格跳过（AC05） | 当前已有英文及德语配置 | 仅法语非空的文件 | 预检并保存 | 法语更新，未提供及空格单元格不清空其他内容 |
| 非法文件（AC05） | 已有当前草稿 | 未知/重复语言、错误编码、多非空工作表、公式、超限、损坏或多数据行文件 | 分别预检 | 整批不应用，显示位置及原因，草稿保持原值 |
| 取消及保存失败（AC08） | 导入文件已预检通过 | 新语言内容 | 分别取消导入、取消编辑及模拟保存失败 | 取消不改原记录，保存失败不部分写入并保留输入 |
| 存量三类对象（AC06） | 上线前已有各状态三类对象 | 新增Release note字段初始化 | 执行初始化并查看 | 全部英文为 `Bug fixed`，无其他语言独立内容，无旧译文迁移 |
| 重复初始化（AC06） | 初始化完成后已人工修改说明 | 再次执行初始化 | 查看已维护记录 | 已维护内容不被重置为默认值 |
| 对象及备注隔离（AC07） | 同产品存在多固件和虚拟版本 | 仅修改当前对象 | 保存并查看其他记录 | 信息抽屉不出现说明编辑器；其他对象、内部备注、组件及发布配置保持原值；再保存基础信息后说明仍保留 |
| 虚拟版本独立（AC09、AC13） | 虚拟版本及组件均配置说明 | APP读取目标虚拟版本 | 通过技术侧提供的接口调用 | 可读取虚拟版本自身说明，不拼接组件 |
| 暂停与停止可编辑（AC02） | 暂停发布、已停止对象 | 修改说明或导入文件 | 分别编辑、预览、导入并保存 | 两态均可保存，输入未被清空，对象状态保持原值 |
| 已发布纠错与读取（AC10） | 已发布对象已有已保存说明A | 纠错内容B | 保存B后按技术侧方式读取；再编辑为未保存草稿C并读取 | 接口后续可读取已保存B；未保存草稿C不可读，不承诺固定刷新时延 |
| APP渲染（AC11、AC13） | 已保存各语言Markdown | 对应语言及缺译语言 | APP调用并渲染 | 本语言有内容则使用本语言，否则英文；Markdown按格式展示 |
| 有关联固件删除（AC12） | 开发中固件关联一个或多个虚拟版本 | 删除固件 | 发起删除 | 阻止直接删除并提示原因，固件、说明和全部关联保持原值 |
| 无关联删除（AC12） | 无虚拟版本关联的固件 | 删除固件 | 按既有删除入口操作 | 按原有状态规则决定；允许删除时说明不残留独立可读记录 |
| 模板不覆盖英文（AC05） | 当前对象已有自定义英文 | 下载空模板，仅填写中文 | 预检、应用并保存 | 英文保持原值；只有中文变更，未配置语言仍使用原英文 |
| Markdown渲染一致性（AC11） | 技术侧已确定统一渲染策略 | 相同Markdown及HTML、链接/图片边界样例、阿拉伯语 | 平台预览与APP读取渲染 | 支持格式和内容一致；不执行HTML或脚本，URL按统一策略处理 |
| 纯空白语言兜底（AC04） | 英文非空 | 非英语仅空格或换行 | 保存并读取 | 按未配置处理并读取英文 |
