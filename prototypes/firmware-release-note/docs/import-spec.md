# Release note 多语言导入说明

更新日期：2026-11-06。用户明确支持Excel/CSV、16语言、Markdown；默认英语 `Bug fixed`，其他语言非必填。

## 对象与模板

入口为固件或虚拟版本列表「操作 → Release note」的独立管理界面，只作用当前对象，不通过导入跨对象更新。开发中、测试中、发布中、暂停发布、已停止、已发布六种状态均可下载模板、导入、预检、应用和保存；对象状态变化不阻断这些操作，也不清空文件或表单、不使已通过预检失效。本说明的“当前表单”和“主保存”均指Release note独立管理表单及其保存操作。

下载模板提供Excel文件与UTF-8 CSV；Excel模板使用工作表记录同一套语言列。一行表头按顺序为：

```text
en,zh,de,fr,zh-Hant,it,pt,es,ar,vi,id,th,ms,ja,ru,fil
```

一条数据行包含该对象各语言的Markdown源码。模板16种语言的数据单元格全部留空；`Bug fixed`仅由对象创建成功或存量初始化提供，导入模板不携带默认英文；不填对象ID或其他业务字段。语言名称与必填性见[PRD §6.2](PRD.md)。Excel单元格可含换行；CSV按标准引号及换行转义保存，允许UTF-8 BOM。

## 应用规则

- 可只提供部分语言列或填写部分语言；非空单元格覆盖当前表单对应语言，空值/纯空白/未提供语言跳过并保留现值。初始化后第一次导入时，这些语言仍未配置并回退英语。
- 合并后的英文必填；可保留创建或初始化的默认英文，不要求导入文件必须再次提供英文。其他语言均非必填。
- 单元格按Markdown文本处理，保留标题、列表、强调、链接及换行等源码；不转换为纯文本。
- 未知或重复语言列、多个对象数据行、格式无法解析等整批阻断，提示位置与原因。空文件或无有效变更提示无变更。
- 预检展示各语言的新增/覆盖/不变/跳过及差异；应用只更新当前表单，主保存后生效。取消或失败不部分更新记录。
- 对象状态在预检、应用或保存期间变化时，合法预检继续有效，已输入内容继续保留，操作和保存不受状态阻断；只有更换/修改文件或继续修改当前表单内容时，才按最新内容重新计算差异。
- 需要清空某一非英语配置时，在表单手动清空恢复兜底；导入空格不承担清空语义。导入、应用与主保存均不因对象处于任一生命周期状态而禁用。
- 主保存仅持久化当前对象Release note说明字段；不改变固件包、虚拟版本冻结状态、对象状态、发布配置、组件、应用对象、内部备注或发布日志。

语言清单参考[产品二级分类多语言说明](https://github.com/HawZZ/root-interactivable-prototype/blob/main/prototypes/firmware-release-note/docs/PRD.md#53-s03语言兜底与-markdown)，本需求文件格式按用户本次Excel/CSV要求确定，不继承其他需求的文件格式限制。具体文件解析、大小限制和接口映射由技术侧处理。

## 仅补充部分语言的保护

例如当前英文为 `Improved connection stability`，仅在模板简体中文格填写中文并导入，英文格留空；应用后英文仍保持原值，所有英语兜底语言继续使用原英文。导入预检必须列出真实变更，只有用户明确填入的非空英文才覆盖当前英文。对象状态变化不改变该合并结果，也不要求重新预检。

## 异常处理及边界验收

- Excel本期采用`.xlsx`模板，CSV为UTF-8（可含BOM）；`.xls`、`.xlsm`及其他扩展名不作为支持格式，选择时提示改用模板格式。文件实际结构须可按所选格式解析，不只检查后缀。
- Excel只接受一个非空工作表，空表忽略；有多个非空工作表则整单拒绝并定位表名，不猜测目标表。
- 一行表头加一条对象数据行，单元格内换行不算新增数据行；16个固定语言代码可缺列，缺列保留表单值。未知/重复语言列、多个数据行、损坏或错误编码、公式单元格（包括有缓存结果的公式）整单拒绝，绝不执行公式，不部分应用，提示可定位的表/行/语言和原因。
- 模板语言格全部为空。导入非空文本才覆盖；空、纯空白或缺列均保留当前表单值（包括现有非英语译文和自定义英语）。判断空白不改写有效Markdown源码，保存保留原始文本和换行；合并后英文去空白判断必须非空。表单手动清空非英语则改为未配置并兜底英语。
- 空文件、只有表头或无有效变更时提示“无变更”，禁止执行应用，表单和已保存数据零改写；不是成功导入，更不是清空命令。
- 文件大小、每格长度和预览资源上限的具体数值由技术依据现有平台确定，并在开发验收前记录和显示。超限预检整单拒绝且零改写；QA必须用技术确定的上限L及L+1验证边界，不以此要求用户决定数值。
- 预检展示新增/覆盖/不变/跳过及差异；应用仅入当前表单，主保存才持久化；取消或错误无部分变更。对象状态变化不使合法预检失效或清空草稿；文件或当前表单内容变化须重新计算差异，保存仅校验说明内容并持久化说明字段。
