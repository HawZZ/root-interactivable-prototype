# 产品二级分类 · 后台交互原型

直接打开 `index.html`，不需要安装或构建。页面内置样本和全部样式、脚本，无外部资源依赖。

主要入口：

- `#categories`：一级分类列表，点击 Baby monitor 行的“二级分类”。
- `#series?category=DEMO_CAT_BABY`：当前分类下的二级分类列表。
- `#create?category=DEMO_CAT_BABY`：新建。
- `#edit?series=DEMO_SERIES_BABY_001`：编辑。
- `#view?series=DEMO_SERIES_BABY_001`：只读详情。

黄色“原型演示”控件可切换加载、空、失败、只读场景；表单内可模拟保存失败和版本冲突，空系列删除弹窗可模拟失败。它们是评审工具，不属于正式平台功能。

右侧“原型批注”随列表、表单和弹窗切换；点击编号或批注可定位。窄屏使用“产品 / 原型批注”页签，产品画布仍为 1440px 并在局部滚动。

所有修改仅在本页面内存中生效；刷新会恢复样本。图片选择只在浏览器内预览。默认英语，支持平台16种语言；其他15种语言缺译字段回退英语。DEMO_ ID与辅助图不代表生产数据或最终素材规范。本交付只覆盖平台，技术侧定义 APP 接入接口。

验证脚本和结果见 `../../verification/`；真实权限、事务、产品既有写路径及读取接口需后续服务端联调。
